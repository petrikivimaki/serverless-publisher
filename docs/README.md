# Papyrus Docs

Papyrus turns a folder of Markdown files into a public, Obsidian-style knowledge base for GitHub Pages. This docs vault introduces the project and also acts as live sample content for testing search, file browsing, backlinks, metadata, tables, code, maps, and wiki links.

## Start here

- [[start/papyrus|What Papyrus does]]
- [[workflow/setup|Setup workflow]]
- [[reference/markdown|Markdown basics]]
- [[reference/extensions/obsidian-and-papyrus|Obsidian and Papyrus extensions]]

## The idea

Keep your writing as plain text, keep your publishing site as static files, and let the browser do the reading experience. Papyrus can load content from a public GitHub repository, or from this local `docs` manifest while you are developing.

> This vault is intentionally small. Replace these notes with your own Markdown vault when you are ready.

## Example map

Papyrus turns a `map` code fence into an interactive component. See [[reference/extensions/obsidian-and-papyrus|the map component contract]] for every property.

```map
latitude: 60.1699
longitude: 24.9384
zoom: 11
marker: true
grayscale: true
label: Helsinki
```
